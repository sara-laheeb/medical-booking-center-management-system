Design System
Modern, premium, minimal healthcare SaaS visual language — built for light & dark themes with full LTR / RTL support.
Foundations
Color
Clinical Teal is the brand core — trustworthy without being sterile. Amber is reserved for highlights, never primary actions. Semantic colors are kept visually distinct from the brand teal to avoid ambiguity in clinical contexts.
Primary — Clinical Teal
Accent — Amber (sparing use)

Typography
Rubik is used across every weight, for both English and Arabic — one unified typographic voice with no visible shift when switching direction. IBM Plex Mono is reserved for data: amounts, IDs, timestamps.

Loading States
Skeletons mirror the real layout's shape — stat cards, a table row, an appointment card — so nothing jumps when content arrives. A brief fade-and-rise handles the moment it does.
